AI Squared is an enterprise data-and-AI integration platform that connects data sources (Snowflake, BigQuery, Databricks, Redshift, PostgreSQL, S3, Salesforce and more) to AI/ML model endpoints (OpenAI, Anthropic, Google Vertex, AWS Bedrock, SageMaker, WatsonX) and then pushes the resulting insights back into the business applications where work happens. The company acquired Multiwoven, the open-source Reverse ETL / composable CDP project, in 2024 and now develops it as the open core of the platform under AGPL-3.0. Its public REST API at api.squared.ai covers connectors, connector definitions, models, catalogs, syncs, sync runs and sync records, authenticated with a JWT bearer token. AI Squared is SOC 2 Type II certified and ships SaaS, cloud, on-premise and air-gapped federal deployments.

**Areas:** Data Integration · Reverse ETL · Artificial Intelligence · Machine Learning · Customer Data Platform · Data Activation · Workflow Automation · Open Source · MCP · Enterprise · A2A

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for AI Squared: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
